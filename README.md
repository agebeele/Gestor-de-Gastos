# Gestor de Gastos (Pesos Mexicanos - MXN) 🇲🇽

Aplicación moderna para organizar tus gastos mensuales, presupuestos, reportes financieros detallados, escaneo de recibos por cámara, sincronización cifrada y seguridad biométrica, **configurada exclusivamente en Pesos Mexicanos ($ MXN)**.

---

## 📲 Cómo compilar e instalar el APK en tu teléfono con GitHub Actions

La app ya incluye el flujo automatizado de GitHub Actions (`.github/workflows/android.yml`) listo para compilar e instalar en tu celular igual que con Motospeed:

1. **Sube tu código a GitHub** (mediante Push o Exportar repositorio).
2. Ve a la pestaña **Actions** en la parte superior de tu repositorio en GitHub.
3. Verás ejecutándose el workflow **"Build Android APK (Pesos Mexicanos)"** (también puedes iniciarlo manualmente haciendo clic en **Run workflow**).
4. Cuando termine con éxito (icono verde ✅):
   - Haz clic en la ejecución.
   - En la sección inferior **Artifacts**, descarga el archivo **GestorDeGastos-PesosMexicanos-APK**.
5. **Instalación en el teléfono:**
   - Abre o descomprime el archivo en tu celular.
   - Toca el archivo **GestorDeGastos-MXN.apk**.
   - Si tu celular muestra una advertencia de seguridad, selecciona **Configuración** y activa **"Permitir la instalación de aplicaciones desconocidas"**.
   - Toca **Instalar** y listo.

## 🌟 Características Principales
- **100% Pesos Mexicanos (MXN):** Toda la interfaz, presupuestos, transacciones, balances y reportes usan el formato oficial en Pesos Mexicanos ($ MXN).
- **Control de Presupuesto Mensual:** Alertas visuales y notificaciones automáticas cuando te acercas o excedes tu límite.
- **Categorización y Búsqueda Avanzada:** Filtra rápidamente movimientos por categoría, concepto, fecha o método de pago.
- **Escaneo Inteligente de Recibos:** Escanea tickets de compra con la cámara para registrar tus compras al instante.
- **Reportes Financieros y Gráficas:** Análisis de ahorro, distribución de gastos y tendencias diarias.
- **Exportación:** Genera estados de cuenta en PDF listos para compartir o guardar.
- **Seguridad Biométrica y Cifrado:** Bloqueo con huella dactilar/PIN y protección cifrada de extremo a extremo.
